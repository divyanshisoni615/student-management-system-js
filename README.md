# Student Management System

A console-based Student Management System built using JavaScript.

## Features

* Display all students
* Add a new student
* Find a student by name
* Delete a student by ID
* Get all student names
* Filter students
* Calculate total marks
* Calculate average marks
* Get passed students
* Get failed students
* Check if any student has failed
* Check if all students are adults
* Find the class topper
